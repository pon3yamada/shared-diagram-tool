# メンテナンス（配布者向け）

このリポジトリを受け取って使うだけなら、この文書は読まなくてかまいません。

## 改良元との関係

図解スキルは配布者が別の場所で改良し、ここへ取り込んでいます。配る形にするため、**意図的に次の差分**を持っています。

- デプロイ（公開）はデフォルトで止めておき、頼まれたときだけ行う
- スキル内の参照を、リポジトリのルートからのパスで書いている
- エラーメッセージを利用者向けの言葉にしている
- `creating-skills` を同梱している
- 公開 URL に名前とランダム 4 文字を付ける
- 公開のしくみの解説 `docs/publishing.md` を置いている

別の場所で改良したら、その変更をここへ手動で取り込み、**上記の差分は保持する**（改良元の SKILL.md で上書きしない）。

## 変更したら

`bash tools/check.sh` を通す（公開スクリプトの文法・公開 URL の組み立て・`docs/publishing.md` の引用がスクリプトや雛形とずれていないか）。PR と main への push では GitHub Actions でも走る。

公開の手順を変えるときは、`deploy-diagram.sh`・`SKILL.md` の PowerShell 版・`docs/publishing.md` の 3 つを合わせて直す。
